Connect an agent to this hub

  1. Add the config above to your client's MCP servers file:
    • pi: user-level ~/.pi/agent/mcp.json (every project) or project-level .pi/mcp.json — replaces the whole { "mcpServers": { … } } wrapper around the snippet
    • Claude Desktop / Cursor / Codex / any MCP client: same mcpServers shape; url + headers work with streamable-HTTP clients
  2. Replace <MCP_TOKEN> with the MCP_TOKEN value from this app's .env (delete the headers line only if no token is set — not recommended)
  3. Restart the agent (pi: /reload or new session) and verify: /mcp or pi mcp list → ainet: connected, 7 tools

Make an agent actually use it

Tools are declared automatically (direct exposure). Normal phrasing works — but for reliable use, paste this into your agent's instructions (pi: AGENTS.md or system prompt):

Web access policy:
- For ANY question needing fresh/external info, use the ainet MCP tools:
  web_search (query) then web_fetch (best URL).
- For infrastructure questions about this network use:
  services_status, tailnet_status, discovery_list, check_service, discovery_run.
- Never claim you cannot access the internet; the ainet hub provides it.

Example prompts

  • 💰 “Search the web for the latest stable release of Crawl4AI and what changed” → web_search + web_fetch
  • 🩺 “Is anything on my tailnet down? Check anything red right now” → services_status + check_service
  • 🔍 “Run a discovery scan and tell me if any new services appeared” → discovery_run + discovery_list
  • 🌐 “Read https://… and summarize it” → web_fetch
